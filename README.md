# Ultimate-Tool-Inventory

Project to finally and once and for all organize all the tools I have hoarded and piled in my garage.

## Project Idea Proposal

Ultimate Tool Inventory is an inventory and maintenance tracker for professional-grade tools acquired from estate sales, auctions, and promotional events.

### Core Features

- Add tools to inventory
- Classify each tool by category (hand tool, power tool, precision tool)
- Track part numbers
- Add a tool to a set (wrench sets, socket sets, plier sets, etc.)
- Remove a tool from a set
- Track warranty expiration dates
- Track retail price and discounted purchase price
- Sort tools by brand tier (top-tier professional to low-tier generic)
- Detect duplicates and replace current inventory item when the new item is better; mark replaced item for sale
- If a set item is lost, add it to a replacement list
- Print or view all tools that need to be replaced
- Track maintenance/recalibration schedules for tools that require service

### Planned Enhancements

- Add more inventory and reporting features as additional needs are identified
